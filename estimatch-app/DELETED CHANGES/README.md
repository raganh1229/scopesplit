# DELETED CHANGES

Files moved here on **April 19, 2026** during the zone detection refactor cleanup. These files are no longer used by the active codebase but are preserved for reference.

## Why These Were Removed

The comparison engine was refactored to send **all line items to Claude in a single API call** with Claude handling zone detection, item pairing, and zone reconciliation. This eliminated the need for:
- Regex-based zone pre-assignment
- Deterministic prematch (disabled, not deleted — `lib/deterministic-prematch.ts` is still imported for utility functions)
- Chunked processing (replaced by single-call approach)
- Various debugging/auditing scripts created during the refactor

### `dead-exports-deterministic-prematch.txt`
Snippet capturing two functions removed from `lib/deterministic-prematch.ts`:
- `isPrematchEnabled()` — gated on `COMPARISON_PROCESSING_PREMATCH` env var
- `runDeterministicPrematch()` — the original text-based regex prematcher

These were superseded by `runVisionPrematch()` (Haiku-extracted items + canonical zones) when the pipeline switched to vision-based extraction. Helper functions used by the removed prematcher (`joinSplitLines`, `findBestReciprocalMatches`, `parseLineToFields`, etc.) **stay** in the active file because `runVisionPrematch` and `parseAllLinesWithZones` still call them. The `COMPARISON_PROCESSING_PREMATCH` env var is now a no-op and can be deleted from any environment configs.
