========================================================================
ROOT CAUSE
========================================================================
The compact prompt format (lineNumber|description|qty) has NO ZONE INFORMATION.
When two zones have structurally similar items (ceiling drywall, wall paint, texture,
carpet — common in bedrooms/living areas), Claude cross-pairs them.

The prematch's zone-aware matching correctly handles this, but only resolves ~8 items
for this set. The remaining 171 lines go to Claude without zone context.

========================================================================
RECOMMENDED FIX
========================================================================
Add zone name to the compact prompt:
  Current:  lineNumber|description|qty unit
  Proposed: lineNumber|zone|description|qty unit

This lets Claude match within zones, preventing cross-zone errors.
Cost: ~1-2 extra tokens per line. Benefit: eliminates the #1 source of errors.
